# Cuppuccino — QR menu

Office 304, 3rd Floor, Nana Varachha, Surat

184 items. Scan the QR, get the menu.

- `index.html` — the whole site, one file plus `assets/`
- `_source/` — the cafe's data: `menu.json`, `cafe.json`, brand assets,
  the print-ready QR standee, and `REVIEW.md` listing everything that still
  needs the owner's confirmation

Rebuilt from the engine at [Milin555/cafe-qr](https://github.com/Milin555/cafe-qr):

    python3 build/render.py cuppuccino

**Demo built from public listings — not commissioned by the cafe.**
See `_source/REVIEW.md` before showing it as theirs.
